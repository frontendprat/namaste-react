# parcel, vite, parcel (Bundlers)

- Bundlers are tools that take your code and assets and bundle them together into a single file (or a few files) that can be served to the browser. They also handle things like transpiling, minifying, and optimizing your code.

# Dev dependencies vs dependencies

- Dev dependencies are packages that are only needed during development, such as testing frameworks or build tools. Dependencies are packages that are required for the application to run in production.

# ^, ~, and \* in package.json

- ^ (caret): Allows updates that do not change the left-most non-zero digit in the version (e.g., ^1.2.3 allows 1.2.4 but not 1.3.0).
- ~ (tilde): Allows updates that do not change the left-most non-zero digit in the version, but only for the last digit (e.g., ~1.2.3 allows 1.2.4 but not 1.3.0).
- - (asterisk): Allows any version to be installed, regardless of the version number.

# package-lock.json vs package.json

- package.json is a file that lists the dependencies of your project and their versions. It is used by npm to install the correct versions of packages when you run npm install.
- package-lock.json is a file that is automatically generated by npm when you install packages. It locks the exact versions of the dependencies and their dependencies, ensuring that the same versions are installed every time you run npm install.

# node_modules folder

- node_modules fetches all the code for all the dependencies listed in package.json and package-lock.json. It is created when you run npm install and contains all the code for the packages that your project depends on.
- Stores transitive dependencies (dependencies of dependencies) as well. It is important to note that the node_modules folder can become quite large, so it is often excluded from version control systems like Git.

# type="module" in <script> tag

- The type="module" attribute in a <script> tag tells the browser that the script is a JavaScript module. This allows you to use import and export statements in your code, which can help you organize your code into smaller, reusable pieces. Because normal browser scripts cannot use import/export, you need to use type="module" to enable this functionality.
